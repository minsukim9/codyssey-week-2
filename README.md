# Python Quiz Game

Python의 기본 문법과 객체 지향 프로그래밍, JSON 파일 입출력, Git 활용 방법을 학습하기 위한 콘솔 기반 퀴즈 게임 프로젝트입니다.

사용자는 터미널에서 퀴즈를 풀고, 새로운 퀴즈를 추가하거나 등록된 퀴즈 목록과 최고 점수를 확인할 수 있습니다.

> 현재 미션 수행 전 단계이며, 기능 구현 과정에 따라 README 내용을 계속 업데이트할 예정입니다.

## 프로젝트 목표

이 프로젝트를 통해 다음 내용을 학습하는 것을 목표로 합니다.

- Python 기본 문법 활용
- 조건문과 반복문을 이용한 프로그램 흐름 제어
- 함수의 매개변수와 반환값 활용
- 클래스와 객체를 이용한 역할 분리
- JSON 파일을 이용한 데이터 저장과 불러오기
- `try/except`를 이용한 예외 처리
- Git 커밋, 브랜치, 병합, push, pull, clone 실습

## 퀴즈 주제

퀴즈 주제는 **Python 기초 문법**으로 선정할 예정입니다.

이번 미션에서 학습하는 변수, 자료형, 조건문, 반복문, 함수, 클래스 등의 내용을 퀴즈로 다시 확인하면서 Python 기본 개념을 복습하기 위해 해당 주제를 선택했습니다.

기본 퀴즈는 5개 이상 작성할 예정이며, 프로그램 실행 후 새로운 퀴즈를 직접 추가할 수 있도록 구현할 예정입니다.

## 개발 환경

- Python 3.14.5
- Git
- Visual Studio Code
- macOS

외부 라이브러리는 사용하지 않으며, Python 표준 라이브러리만 사용할 예정입니다.

## 실행 방법

프로젝트 저장소를 복제합니다.

```bash
git clone <GitHub 저장소 URL>
```

프로젝트 폴더로 이동합니다.

```bash
cd <프로젝트 폴더명>
```

다음 명령어로 프로그램을 실행합니다.

```bash
python3 main.py
```

## 주요 기능

다음 기능을 구현할 예정입니다.

### 1. 퀴즈 풀기

- 저장된 퀴즈를 순서대로 출제
- 선택지 4개 출력
- 정답 번호 입력
- 정답 및 오답 결과 출력
- 전체 퀴즈 결과와 점수 출력

### 2. 퀴즈 추가

- 새로운 문제 입력
- 선택지 4개 입력
- 정답 번호 입력
- 추가한 퀴즈를 `state.json`에 저장

### 3. 퀴즈 목록

- 등록된 퀴즈 개수 출력
- 저장된 퀴즈 문제 목록 출력
- 등록된 퀴즈가 없는 경우 안내 메시지 출력

### 4. 점수 확인

- 퀴즈 플레이 결과 확인
- 최고 점수 확인
- 기존 최고 점수보다 높은 경우 최고 점수 갱신

### 5. 데이터 저장 및 불러오기

- 퀴즈 목록과 최고 점수를 JSON 파일로 저장
- 프로그램을 다시 실행해도 기존 데이터 유지
- 데이터 파일이 없거나 손상된 경우 기본 데이터로 복구

### 6. 예외 처리

- 빈 입력 처리
- 숫자가 아닌 입력 처리
- 허용 범위를 벗어난 입력 처리
- `KeyboardInterrupt` 처리
- `EOFError` 처리
- JSON 파일 읽기 및 쓰기 오류 처리

## 클래스 구조

프로그램은 최소 두 개의 클래스로 역할을 분리할 예정입니다.

### `Quiz`

하나의 퀴즈 정보를 관리하는 클래스입니다.

주요 속성:

- `question`: 문제
- `choices`: 선택지 목록
- `answer`: 정답 번호

주요 메서드:

- 퀴즈 문제와 선택지 출력
- 사용자 입력과 정답 비교
- JSON 저장을 위한 데이터 변환

### `QuizGame`

퀴즈 게임 전체 흐름을 관리하는 클래스입니다.

주요 속성:

- 퀴즈 목록
- 최고 점수

주요 메서드:

- 메뉴 출력
- 메뉴 입력 처리
- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 출력
- 최고 점수 확인
- 데이터 저장
- 데이터 불러오기

## 데이터 파일

퀴즈 데이터와 최고 점수는 프로젝트 루트의 `state.json` 파일에 UTF-8 인코딩으로 저장할 예정입니다.

예상 데이터 구조는 다음과 같습니다.

```json
{
  "quizzes": [
    {
      "question": "Python에서 여러 값을 순서대로 저장하는 자료형은?",
      "choices": [
        "int",
        "bool",
        "list",
        "str"
      ],
      "answer": 3
    }
  ],
  "best_score": 0
}
```

각 필드의 역할은 다음과 같습니다.

| 필드 | 설명 |
|---|---|
| `quizzes` | 등록된 퀴즈 목록 |
| `question` | 퀴즈 문제 |
| `choices` | 4개의 선택지 |
| `answer` | 정답 번호 |
| `best_score` | 사용자의 최고 점수 |

`state.json` 파일이 존재하지 않는 첫 실행에서는 프로그램 내부의 기본 퀴즈 데이터를 사용할 예정입니다.
